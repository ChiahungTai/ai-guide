## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
建立 Code Lens 上位概念，把 code tours 的 narrative/sequence 與 pr-lens 的 topology/relationships/impact 統一成同一 human viewport family。Code Lens 不是 lifecycle node、也不是第二 truth source；它由 card tree + git/code-reality/symbol graph/review facts 按需投影，在 entry/exit Align 或 user 隨時要求時呈現。要定義 Tour / Graph / Impact / Diff / Architecture 等 view 的共用 fact contract、何時預計算 facts、何時 lazy render，以及 Report Shell、/illustrate 與 Code Lens 的邊界。原 AIR-135 v1 pr-lens flow graph 作 dogfood evidence，不綁死最終 UI。
<!-- SECTION:DESCRIPTION:END -->
