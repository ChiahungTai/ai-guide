# Harness 掌控面能力矩陣（control-plane matrix）

> **定位**：[contracts.md](contracts.md) 管「harness 能做什麼」（A 層官方契約詳細單一源）；本檔管「**這台、這版本、這 surface 實際掌控到哪層、證據到哪層**」（operational projection，AIR-138）。A 層格子只放斷言＋鏡像 `file:line` 錨點（詳細契約以 contracts.md＋鏡像為準，不重抄）；B 層格子只放**結論狀態＋authority pointer**——manifest 有權威面引 manifest key，非 manifest 面標各自 authority，definition 不複製。
>
> **維護**：鏡像新增／更新／退役流程掛點見文末「LIFECYCLE 掛點」節（掛點引用句由 LIFECYCLE.md 持有，本檔持有 checklist 本體）。

## B 層狀態 vocabulary（本檔唯一定義）

| 詞 | 定義 |
|----|------|
| **wired** | 已接線且驗證存活——authority（manifest key 或標明之 authority）有註冊面，probe／receipt／live config 至少一者在場 |
| **partial** | 部分接線——有註冊面但覆蓋或驗證不完整，或有已登記缺口（見 gap register） |
| **unwired** | harness 有此 native 能力、ai-guide 未接 |
| **n-a** | 該 harness 無此 native 面，或對 ai-guide 工作流不適用 |
| **unknown** | 未查證／無法機械驗證——禁凭目錄直覺填 wired |

## 每格屬性

- **act**（activation/reload boundary）：變更何時生效——即時／新 session／per-session 快照／重 approve。
- **trust**（trust/approval gate）：誰核可——無 gate／manual UI／plugin approve／project trust／policy。
- **ev**（證據層級）：`official`（鏡像 file:line）｜`current-config`（本機 config 讀值，附盤點日）｜`runtime-probe`（probe/receipt）。

observability 維（row 15）另按「**configured ≠ loaded ≠ trusted ≠ fired**」四態結算：註冊面在場（configured）、runtime 載入（loaded）、通過 trust/approve（trusted）、實際觸發過（fired，需負向或正向行為證據）。
