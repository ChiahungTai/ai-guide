載體

獨立 user-scope plugin，不搭 delegate plugin——不委派也用 muse 的人不被迫裝；memory 政策不綁 delegate 發版節奏。

opt-in marker

明確版本化 memory-governance.json（protocol:1）——不是偵測目錄存在（普通 add_memory 會自建目錄、偽造 opt-in 的 bootstrap trap）。

遷移零重疊

plugin 見到可工作的 legacy 閘就讓位（no-op）——不雙跑、不重複收據；逐 repo 切換後才刪舊接線。

安全邊界

untrusted workspace 的 suppress 是合理邊界不繞過；惡意 repo 放 marker＋symlink inbox 的導流寫入導彈会被逐段 lstat 擋下。
