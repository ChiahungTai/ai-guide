P1 池 git 基線＋diff-driven 收斂 計畫中

  • ai-rules 池（CC 真目錄＝唯一實體；zcode 路徑 symlink）一次性 git init＋.gitignore 三項（__pycache__/＋暫態 marker）＋基線 commit；remote 不設（local only）。
  • 層 3 波次骨架改 diff-driven，波前二分：dirty 且全部 mtime>30min→流入快照 commit 後開波（否則日常流入使池常態 dirty、流出腿停擺）；任一 <30min（活躍 writer）→停波報告。波後 diff --stat → commit 或 discard；mtime 稽核保留互補。
  • 實彈 drill 驗收 SM-1（壞編輯→discard）/SM-2（誤刪→單檔還原）/SM-6（.git 在場 regen＋開場面不變）/SM-7（髒檔停波）。

P2 telemetry→decay 候選 計畫中

  • decay subcommand（複用 reads 路徑）：三規則＝零讀→unused（沿用 hot/近 30 日 mtime 豁免語義，與層 2 同判準）／usage_count 升序＋last_read／last_read 距窗尾 > 30 天→衰減；輸出固定路徑 <pool>/_decay-candidates.{json,md}（`_` 前綴不進投影）＋rank 升級候選段。
  • 夜波①第一步＝跑 decay 產出→併入報告人裁——只產候選不自動刪；驗收＝單元釘規則邊界＋L4 首份清單。
  • 驗收＝單元測試釘三規則邊界＋L4 對 live 池跑出首份 decay 候選清單。

P3 注入安全條款 計畫中
