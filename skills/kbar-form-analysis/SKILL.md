# Skill: kbar-form-analysis
# /kbar-form-analysis — K 線形態判讀 pipeline（雙視圖＋數值混合契約）

> **用途**：需要對 K 線形態做**獨立判讀**的任務——標記輔助（人審模擬）、誤判歸因、策略形態複核、批量掃描。把「人看圖判斷」拆成可重複的 agent pipeline：**任務側產圖工具＋混合證據包＋vision agent 合約＋分層保證**。

## 核心設計：三證據層（缺一即偏）

| 層 | 載體 | 回答 | 實證缺層後果 |
|----|------|------|-------------|
| **focus 焦點圖** | 近期 K 線＋指標線（標記事件/窗） | setup 形態**幾何**（糾結/扇形/支撐結構/斜率） | 只剩數值→agent 從聚合值反推幾何、甚至手算均線位置 |
| **background 背景圖** | 多年期壓縮週期（如週K ~200 棒） | **前提**（前段方向/長期位置/基底與長期基準線軌跡） | 近視盲——深回檔被讀成崩跌反彈（-55% 實為多年上升結構的回檔不破基底）；反向也成立（崩跌末端盤整被讀成長期橫盤） |
| **數值包** | 文字（OHLC/特徵/門檻/翻轉分析） | **量化對照**（貼界多近、量比、閾值差距） | 圖讀絕對量級易誤；貼界數字是分類存亡的機械事實 |

三層由**同一判讀 agent 並讀**（focus→background→數值），合約強制它對三源自評「哪源對結論最關鍵」——自評結果是流程改進的情報（某源長期最關鍵＝該源特徵化的動機）。

## 產圖契約（第一紀律：週期宣告）

- **每圖燒 own 週期＋指標期數單位**（`K線週期：1d/1w/5m`——MA 期數是**棒數非日曆**：5m 棒的 MA25≠一個月；雙視圖兩圖期數單位不同，圖題分別宣告）
- **圖題不做權威源**（agent OCR 可能誤讀）——caller prompt 自帶 header 重複宣告
- 標記語義明確：事件虛線（▲發動點/D~E 區間）＋窗底色＋圖例；量軸標單位
- 長期線短歷史 null（上市年數 < 線期）→ agent 報「未見」是**正確行為**（誠實 scope），fallback 短一期線
- 產圖工具在**任務 repo**（渲染原語重用該專案圖表庫——如 mosaic `tools/kchart_case_render.py`：focus 日K＋background 週K，`--view both`）；headless 匯出＝HTML→playwright 截圖

## Agent dispatch 合約（vision-review 為載體——**定義不改，任務知識全在 caller prompt**）

七項清單（每項論述須引**日期/價位/量**為證，禁無證據形容詞）：

1. **錨點檢查**：圖元素在場確認（指標線/標記/窗底色/量副圖）——缺項明說，兼驗渲染缺陷
2. focus 形態（窗結構/量能變化/關鍵棒）
3. focus 指標幾何（收斂/扇形/分層、價-線相對位置、斜率）
4. background 長期結構（本案落在長期走勢哪裡/前段漲跌盤＋幅度/長期基準線方向與距離）
5. 事件後行為（突圍方式/延續或失敗）
6. 判讀（依任務定義的類別）＋**背景圖有沒有改變只看焦點時的判讀**——同意/推翻既有判定＝盲判產出後由 caller 對照浮現（既有結論不進包，見合約紀律）
7. 一句話結論＋三證據源自評

合約紀律：
- **盲判**：人標/既有結論不進包（防引導偏差；分歧＝浮出候選，非缺陷）
- **語義圖例進 prompt**：欄位命名的慣性陷阱要顯式拆解（如 maN_min 的 N=組編號非天數——無圖例時判讀 AI 會誤讀）
- **抽棒對照**（可選但建議）：agent 引用的收盤價對照數值包 OHLC，不符即 FAIL——agent 兼任圖的驗證器

## 保證層（fail-visible 而非 fail-proof）

| 層 | 問題 | 機制 |
|----|------|------|
| 圖對嗎 | 渲染正確 | 指標線與特徵管線**同源**（圖錯先炸在下游特徵）；已知形態案自驗（先簡單案再難案）；錨點檢查＋抽棒對照 |
| 讀對嗎 | agent 判讀 | 證據通道交叉（純文字/單圖/雙圖三路線）；難案（低分/貼界/分歧）**雙 agent quorum**，分歧升 user |
| 歸納對嗎 | corpus 結論 | 推翻案全歸因可追溯＋機械統計對照＋口徑自律（只宣稱抽樣段性質，不外推全池） |
| 標準對嗎 | 判讀定義本身 | **user 人審是唯一最終真相**——pipeline 產出＝複審候選清單＋批量同意的信心基礎 |

**誠實限制**：多路線的證據通道獨立、**裁判同模型家族**（quorum 對共同盲點無效）——裁判層盲點由 user 兜底；分歧案直接升 user 裁決，不由 AI 仲裁。

## 已知坑（實證）

- **量級誤讀**：agent 讀圖絕對量級偶誤（176 張→「17.6萬張」）——**比值可靠**（前日 N 倍）、絕對值對照數值包
- **圖題 OCR**：CJK 圖題可能被誤讀——prompt 自帶 header（重複宣告）
- **定義邊界案**：判讀分歧常指向**定義本身的邊界語義**（如「深回檔變體算不算某類」）——這是 pipeline 的最高價值輸出（定義修訂候選），升 user

## 消費形態

- **單案複審**：誤判嫌疑案/邊界案 → 雙圖＋agent 預判 → user 裁決
- **批量掃描**：低信心池選案（每類別信心升序）→ 批量產圖＋平行 agent → 判讀表 → user 掃同意/推翻（掃描池本身經設計＝高誤判密度）
- **Refit/規則修訂循環**：規則更動前後的 corpus 對照掃描
